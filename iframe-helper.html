AIM-I · Joomla iframe 複製工具

把你的 GitHub Pages 網址填入下方，所有 iframe 程式碼會自動更新，然後逐頁複製貼入 Joomla。

使用步驟：
① 上傳 HTML 檔案到 GitHub Pages，得到網址（例如 https://nknu-aim.github.io/web）
② 把網址貼入上方欄位，按「更新所有程式碼」
③ 到 Joomla 後台，開啟對應選單頁面，切換成「原始碼」模式
④ 點「複製」，貼入 Joomla 編輯器，儲存
